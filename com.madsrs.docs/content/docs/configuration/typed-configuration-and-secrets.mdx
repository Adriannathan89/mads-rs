Typed configuration is an explicit view over the already loaded `Config`. Derive `Configuration` and parse it from a selected provider.

```rust
use mads::prelude::*;

#[derive(Configuration)]
#[config(prefix = "app")]
struct AppConfig {
    #[config(default = 3000, validate(range(min = 1, max = 65535)))]
    port: u16,
    api_key: Secret<String>,
}

#[provider]
fn app_config(config: Config) -> mads::core::Result<AppConfig> {
    Ok(config.parse()?)
}
```

## Parse only what the selected graph needs

`Config::parse` does not reload source files or discover configuration types globally. If the provider is selected, missing, invalid, and validation errors stop startup before lifecycle hooks and listener binding.

### Protect secret values

`Secret<T>` is redacted in `Display` and `Debug`. Expose it only at the point of use with `.expose()` or `.into_exposed()`. Do not put production secrets in tracked TOML files.
