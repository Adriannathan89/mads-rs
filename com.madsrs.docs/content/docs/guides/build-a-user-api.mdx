title: Build a user API
description: Compose a modular user API with a thin HTTP edge and explicit infrastructure.

Build the feature boundary before choosing infrastructure. The starter does not need a database, JWT, or cookies; add PostgreSQL, authentication, and cookie transport only when the use case requires them.

## Define the feature boundary

Keep the user capability in its own module. The module can own its controller, service, repository provider, and optional Passport strategy declarations.

```rust
use mads::prelude::*;

#[module]
pub struct UserModule;
```

### Validate delivery input

Use an `Input` type with `ValidatedJson` at the HTTP edge. The controller validates and translates the request, then calls a service or use case. Do not put persistence, password policy, or ORM response conversion in the handler.

```rust
#[derive(serde::Deserialize, Input)]
struct CreateUser {
    #[input(length(min = 3, max = 40))]
    name: String,
}
```

## Add the database behind a contract

Define a repository trait that represents what the user service needs, then bind a concrete implementation through a provider. With MADS-managed Diesel, the repository receives `Database` and runs synchronous queries with `Database::run`. With an application-owned ORM, import a database module and receive its connection type instead.

The clean-architecture guide walks through this Trait → Provider → Repository → Service arrangement and links to a complete working example.

## Add optional delivery concerns

When authentication is needed, configure JWT explicitly and register a managed Passport strategy. Cookies are a separate transport choice, not a starter default.

## Compose the application

The composition root imports the user module and starts only the resulting graph.

```rust
use mads::prelude::*;

#[module(imports = [UserModule])]
struct AppModule;

#[mads::main]
async fn main() -> Result<(), HttpRuntimeError> {
    Mads::run::<AppModule>().await
}
```

This root is runnable once `UserModule` and its selected dependencies are defined.
